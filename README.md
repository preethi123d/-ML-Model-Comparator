# -ML-Model-Comparator
A Streamlit web app that compares multiple ML models on any CSV dataset — supports both tabular and text data with NLP pipeline

This project is a Machine Learning Model Comparator built using Python and Streamlit.
Upload any CSV dataset, select your target column, choose Classification or Regression,
and the app automatically runs 5 ML models and compares their performance side by side.

It also supports text/NLP datasets using TF-IDF vectorization with N-gram selection,
making it useful for tasks like spam detection, sentiment analysis, and text classification.

Built to showcase core ML and NLP concepts learned during certification — including
KNN, Decision Trees, Random Forest, SVM, Logistic Regression, Linear Regression,
and evaluation metrics like Accuracy, F1 Score, MAE, and R2 Score.
